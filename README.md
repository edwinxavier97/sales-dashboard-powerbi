# Sales Performance Dashboard
Overview- This project is a Power BI dashboard built to analyze sales performance across regions, categories, and products.

Key highlights--
South region has the highest sales
Electronics category dominates overall revenue
Phones and laptops are top-selling products

Tools used--
Power BI
DAX
Data Modeling

Features--
Interactive slicers
KPI cards (Total Sales, Quantity, Avg Sales)
Visual breakdown by Category, Region, Product

Screenshort added
